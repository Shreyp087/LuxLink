# Requests for comments

RFCs are time-bounded proposals for cross-team, user-visible, or experimentally uncertain work. They invite evidence before a durable decision is made.

## Process

1. Copy `0000-template.md` to the next zero-padded number and short title.
2. Set status to `Draft`; name the driver, required reviewers, and decision deadline.
3. Open a pull request and request every affected owner from the team operating model.
4. Resolve questions with evidence or a named experiment.
5. Close as `Accepted`, `Rejected`, or `Withdrawn`.
6. For durable accepted choices, create an ADR and link it from the RFC.

RFCs do not override accepted ADRs. Proposals that would do so must explicitly supersede the prior ADR with a new one.
